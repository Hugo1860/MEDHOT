# 临床阅读模块

公开入口 `/clinical`、`/clinical/items/:id`、`/clinical/weekly`、`/clinical/questions`；审核入口 `/clinical/manage`。覆盖全部既有专科/主题标签。当前版本的工程能力与临床验收边界见下方“完整功能迭代”。所有公开数据经过统一publication读取层，读者访问不调用模型。

新增官方源在 `industry/sources.json`，初始导入最多 8 条、默认仅摘要与原文链接。2026-11-09 云端预览：国家疾控局 50 条、中国疾控中心呼吸道监测 12 条、WHO 最新出版物 4 条、Cochrane 动态 10 条。NICE 云端 403；药审中心云端响应不符合 HTTP/1.1；卫健委与药监局 412；器审中心 202 校验页；ChiCTR 暂未取得可用批量注册信息接口。这六项保留停用记录，不绕过访问校验，不以旧 RSS、首页导航或注册指南冒充新内容。恢复时必须先在云端预览成功再启用。WHO 所用栏目只覆盖最新出版物，Cochrane 所用栏目是循证新闻，不能视为其全部指南或综述收录。

2026-11-10 复查进一步确认：药审中心对本站采集身份返回 `HTTP/1.0 403 Forbidden`，状态行只有 LF 换行，因此采集器显示协议错误；通用浏览器身份返回 200 不能用作生产采集验收。`scripts/probe-sources.ts` 已改用与采集器一致的身份、SSRF 防护和出站路径，并保留错误原因链。ChiCTR 检索页返回 405，仍无已验证的批量接口。[NICE 官方 API](https://www.nice.org.uk/reusing-our-content/nice-syndication-api) 要求机构申请、说明 AI 用途、取得许可和密钥；境外使用可能收费。取得授权后应配置获准的 API/订阅接口，不能直接启用旧网页配置。

恢复接入所需条件：卫健委、药监局、药审中心、器审中心需要来源方允许的机器访问方式或数据接口；ChiCTR 需要官方批量访问/导出方式；NICE 需要获准的使用范围和 API 密钥。只向原站低频请求已知公开入口，不使用浏览器 Cookie、代理换身份或放宽地址校验来处理拒绝访问。授权资料、接口地址和密钥就绪后，再完成预览、真实采集、模型处理及前台核验。

人工核查入口：[卫健委](https://www.nhc.gov.cn/)、[药监局](https://www.nmpa.gov.cn/)、[药审中心](https://www.cde.org.cn/)、[器审中心](https://www.cmde.org.cn/)、[ChiCTR](https://www.chictr.org.cn/searchproj.html)、[NICE](https://www.nice.org.uk/guidance/published)。不自动作试验注册与发表结局一致性的医学判断，管理员可核对并登记依据。

初版迁移 0128–0131 仅新增模块表与索引；本轮新增0132–0143，无旧数据删除。模块测试验证依据过滤、数值拒绝、付费回执与不重复提取、北京时间周期、撤回内容与过期资料即时排除。浏览器测试验证专科筛选、保存条件、周报跳转及证据卡缺失/复核状态。

## 2026-11-10 完整功能迭代（工程交付，非临床验收）

新版证据摘录保存 `schema_version=2`，25项事实字段、按结局分组的比较/时间/亚组/效应/伤害、研究类型、人群和原文确定性、带依据的干预与结局标签、分研究类型的批判性阅读摘录。新增证据卡仍经过模型回执与预算；旧卡在worker分批升级时继续显示既有内容，未完成的字段不能当作已经提取。逐字依据仅供后台核查，不从公开接口分发。数值和逐字依据校验只能检查出处，不能证明医学解释正确。

公开页面：适用性三块、缺失原因、院内核查有效期、结局分组、分类型阅读清单、版本前后字段、注册快照对照。`/clinical`新增design、patient、certainty、publication、interventionTag、outcomeTag、reviewed、subspecialty、mode、role、after筛选；晨读最多5条、深读展开PICO/局限、值班显示安全/撤稿/关注声明。科室/亚专科关键词/角色偏好及临床问题仍只存本浏览器；角色用于阅读提示，不伪装成临床验证过的推荐排序。亚专科关键词不是已审定分类表。收藏问题可查看新增或有版本事件的资料，手动标为已查看。

`/clinical/manage`提供审核分配、截止时间、受保护的原始材料、院内药械/医保/设备/基线风险核查、注册快照、医师标注、资质登记、周报审阅发布。所有私有读取需管理员；写入检查会话、CSRF、版本并审计。个人身份复用已有飞书管理员账号；机构资质登记需另一管理员核验，不能自我认证或绑定共享密码。共享密码提交明确显示代录，不等同专家本人签署。临床负责人暂未安排，不预填真实审核结论。

人工复核绑定资料修订及证据卡生成时间；重新提取后旧复核不再显示为当前有效。院内核查过期和旧版本保留但明确标记。注册记录需与已摘录注册号匹配；对照仅表示文本相同/不同/缺失，不能自动断言选择性报告。ChiCTR自动查询仍依赖获准接口。

撤稿监测使用Crossref原记录与`updates:DOI`反向公告查询（包括其收录的Retraction Watch数据）；解析出版商预印本/替代/版本关系；使用明确PMID或唯一DOI映射查询PubMed关联。每个渠道分别展示完成/失败/无法覆盖；无关系不能证明无撤稿。无密钥NCBI请求按每秒少于3次限制。成功核查周期24小时；有真实渠道错误时15分钟后可重查。相关说明：[Crossref筛选](https://www.crossref.org/documentation/retrieve-metadata/rest-api/rest-api-filters/)、[Retraction Watch](https://www.crossref.org/documentation/retrieve-metadata/retraction-watch/)、[PubMed关系方向](https://dtd.nlm.nih.gov/ncbi/pubmed/doc/out/250101/el-CommentsCorrections.html)。

`clinical.relations`每小时从最近500条有效卡寻找相同注册号和同来源规范化同标题指南候选。候选只在后台展示，不自动把同一试验的不同结局合并，也不自动宣布新版替代。无标识或标题不同的指南仍需人工发现；临床问题新资料提示不等于自动重新评价整个证据体系。

周报使用草稿→已审阅→已发布→已更正状态。自然周结束后才能发布；已审阅的内容或引用版本变化须重新审阅。公开历史周报保留所选资料ID和编辑版本，引用从统一公开层重新判断；撤回内容移除，其依赖讨论也隐藏。打印副本不会自动更新，应核对在线版本。

评测支持准备最多200条待标注真实资料（包含被预筛排除的资料）、保存医师标签与审计、按研究锁定开发/留出分组、记录分歧、导出一致标注供现有SelectBench使用；无样本显示未评估。默认不调用付费评测，不改变评分门槛。样本之外的采集漏报需外部人工清单才能评价。不能将一组样本的结果外推为全部22个专科已通过临床验收。

当前外部依赖：临床协调人/专家与100–200条真实标注尚未安排；用户已确认同一维护范围包含信源接口及院内药械/医保/设备资料，具体接口配置位置、授权与资料仍待提供；六条暂停信源的授权未就绪。具体进度以`docs/clinical-delivery.md`为准。


科室临床问题由管理员登记PICO/关键词及维护人，`/clinical/questions`公开相关证据、复核登记与变更提示。定时核对证据集合，公开读取时再次计算指纹；新增证据、证据卡再生成、出版状态变化或撤回使旧结论立即失效。暂停问题保留历史，可恢复。没有真实临床问题和专家登记时明确显示空状态，不自动生成医学结论。

真实模型返回曾将研究分类包装成`{value,evidence}`，导致旧验证器拒绝整批。现在保留可核查的分类值、将无法识别的分类记为未知；某条输出仍不可用时记录提取问题并继续其他资料，该条停止自动付费重试，由维护人在工作台核查后解除。相同原材料与提示词的已付费失败回执若通过当前验证器，可直接恢复并在审计中标记复用，不再调用模型；预算或服务错误仍保留原熔断行为。


最终提取提示词为`clinical-3`，持久化卡片仍为`schema_version=2`：结局使用值和同名`Evidence`平级字段返回，服务端归一化为既有公开结构，减少真实模型的嵌套JSON错误。对象缺少值或原文依据时该字段保持未知，不凭空补全。既有合格新版卡不重复付费重提取。卡片再生成会触发出版状态重新核查，页面在刷新前标明历史核查记录；人工更正/撤稿关联也使临床问题旧结论失效。


## AI材料复核与证据卡展示（2026-11-10）

用户确认暂时不安排人工验收，先使用AI处理。`clinical.review`后台任务每5分钟复核最多10张需要复核的当前证据卡；带“中文”信源标签的资料免AI确认复核，复用“临床证据摘录与AI复核”模型配置，所有请求通过既有回执和预算。复核材料类型、已填字段与原文一致性及完整性；同一版本不会重复请求。新卡、资料版本或复核提示词更新会重新排队。数据库保留微秒精度的卡片版本，避免Date毫秒精度导致重复付费；执行期间卡片变化时不将结果绑定到新卡。

新增0144仅保存AI复核及回执，不修改医师标注、人工资质、临床评分或精选门槛。模型无效输出按卡片隔离，停止同版本自动付费重试，后台可记录依据后安排重试；预算熔断及服务异常仍走现有框架。AI复核与摘录默认使用同一已配置模型，不声称不同模型交叉验证或临床专家验收。

外文及未标明中文的信源展示规则：没有实质临床字段（仅DOI等元数据不算）或AI发现摘录依据问题时隐藏卡片；未完成AI复核、摘要/报道/不能确认完整的材料或关键字段不足时默认折叠；只有当前AI复核完成、无已发现问题、识别为全文且关键临床字段完整才默认展开。AI认定全文还须提供至少两段原材料内可定位的依据，且采集材料未截断；这仍不是人工全文核验。字段充分性按研究/指南结构判断，未调整精选评分门槛。缺失字段单独折叠，内部引用段不公开。

普通摘要、原文链接与撤稿/安全提醒始终保留。“无需复核或AI复核已完成”筛选包含中文免复核资料，人工复核筛选保持独立；后台显示AI进度，失败可审计重试。AI复核变更同时使科室问题旧证据指纹失效。没有院内资料或获准接口时，AI不会编造已核实结论或代写医师验收记录。


## 隐藏证据卡修复与原文补充（2026-11-10）

真实审计发现217张公开卡有AI问题、25张无实质字段、7张被判材料为空，合计249张隐藏；202张已有正文，但其中32张是期刊加载失败模板。原复核误把缺失字段、正确文件类型及“有据但未写全”的内容列为错误。新版clinical-review-2要求每项问题引用实际已填断言及精确字段路径，合理缺失仅影响充分性；clinical-5重新核对有问题的旧摘录，不修改精选门槛或把AI记成人工验收。

clinical.materials每15分钟最多补查2条资料，每个文章版本只查一次，受COLLECT_ENABLED约束。沿用采集身份与出站保护，仅请求原网页、网页明确链接的主文档以及Europe PMC按DOI/完整标题唯一匹配的记录；开放全文XML只在isOpenAccess=Y时请求并核对DOI。不使用浏览器Cookie、代理换身份或付费墙绕过，不启用停用信源。HTML、PDF文字层、索引摘要分别记录来源、哈希、时间及获取结果；附录不冒充正文。Docker增加poppler-utils，不支持文字层的PDF保持未取得。

新增0145存储内部补充材料，不替换文章原文、原有摘要和传播许可。补料后旧卡/AI结果失效，重新提取后再审；页面只增加补充来源链接和材料类型，正文只可在已有管理员材料接口读取。AI输入上限为120000字符，超长材料明确标记部分读取，不能确认成完整全文。失败/无更新的获取记录保留；不自动重复付费重试。

本轮进一步核对发现，中文期刊的加载失败正文之外仍有公开citation_abstract元数据。补料同时读取DOI匹配的出版商摘要及其声明的同站摘要页，并明确标为摘要；数学符号缺失不猜补。补料、重提、再审按依赖顺序执行，等待材料的旧卡不先付费重跑。公开链接使用原请求地址，避免携带临时跳转参数。

针对现场出现的统计小于号被误当标签，补料清洗保留 P<0.001 及后续结局/伤害段落。当前来源及提示词下，在首次提取后允许一次带具体AI问题的纠错；计数存入卡片、变更记录保留问题，达到上限仍有问题则继续隐藏，等待维护人核查，防止反复付费。来源改变后重新计算。后台材料区同时展示原始和补充材料，便于核查实际输入。


## 中文信源无需AI确认复核（2026-11-10）

按使用者明确要求，后台信源标签含`中文`的来源不调用`clinical.review`，不等待人工或AI确认即可展示已提取证据卡。依据是信源配置，不是已翻译的标题、机构所在地或文章语言猜测。在后台“信源”的标签中维护；本次为六个中文期刊、国家疾控局和中国疾控中心，以及五个仍暂停的中文官方来源添加该标签。暂停状态不变。

公开接口返回`aiReviewRequired=false`、`aiReview=null`，页面和后台显示“中文信源无需AI确认复核”，不计作已完成AI复核或人工验收。含实质临床字段的卡片默认折叠，可直接展开；空卡继续隐藏。逐字段原文引用和数字校验、材料版本失效、原文补料、AI摘录、评分、撤稿与安全提醒照常运行。免复核不推定已取得全文或更高证据等级。

中文来源的旧AI问题不再触发额外纠错提取；旧复核活动记录和重试标记清除，回执及历史审计保留并增加免复核事件。后台重试接口拒绝中文来源，未完成的在途调用保留已产生回执，但不再写入新的复核状态。去掉`中文`标签后重新按普通来源排队。原文补料不依赖中文来源存在复核记录。

查询参数`aiReviewed=true`现对应“无需复核或AI复核已完成”，不会把免复核资料排除在已保存筛选之外；`reviewed=true`仍仅匹配真实人工复核记录。AI策略变化使科室问题旧证据指纹失效。

临床阅读首页同时显示中文信源总数和“查看中文信源数据”入口。`sourceLanguage=zh`仅使用信源的`中文`标签，按发布时间在中文资料内部排序；`sourceLanguage=other`查看其他来源。这个入口解决中文资料因时间较早落到后续分页而难以发现的问题，不改变文章时间、关注度、精选判断或证据卡展示门槛。
